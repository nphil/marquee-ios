# MarqueeCore API

`Packages/MarqueeCore` holds everything that does not draw: the Plex client, the choice of server address, the library calls, the audio and subtitle rules and the playback route decision. It uses Foundation (plus Observation for `PagedLoader`); `Security` appears only in `KeychainStore`, which compiles on Apple platforms only. Public types are `Sendable` and network calls are `async`. The behaviour follows `docs/behaviour-spec.md`.

## Plex client (`Plex/`)

- `PlexClientIdentity`: the app as Plex sees it. `headers(token:)` gives the `X-Plex-*` headers; `storedClientIdentifier(in:key:)` creates the install's identifier once and keeps it.
- `PlexHeader`: Plex header names.
- `URL.removingPlexToken`: the URL without `X-Plex-Token`, for log lines and cache keys.
- `PlexTransport`, `URLSessionTransport`: send one request; URLSession errors become `NetworkFailure`.
- `PlexRequest`, `PlexHTTPResponse`, `HTTPMethod`: request and answer values.
- `PlexURL.make(base:path:query:)`: joins a base, a Plex path and a strictly encoded query.
- `PlexHTTPClient` (actor): adds identity and token headers. `send` retries a read once after a dropped connection, never a write or a timeout; `decode` parses JSON off the actor; `setToken` after a profile switch.
- `PlexError`: `unauthorized` (401), `unreachable(NetworkFailure)`, `server(status:message:)`, `decoding`, `pinExpired`, `profilePINRejected`, `noConnections`. Carries no token or URL, so it is safe to log.
- `PlexMediaContainer`, `PlexMetadata`, `PlexMedia`, `PlexPart`, `PlexStream`, `PlexMarker`, `PlexChapter`, `PlexRole`, `PlexHub`, `PlexDirectory`, `PlexLibrarySection`, `PlexMediaType`: Plex JSON. Every field is optional and read whether Plex sends `"1"`, `1` or `true`; a bad field never drops its item.
- `PlexMetadata.markers(_:)`: intro, credits or commercial markers in playback order. `onDeck`: the episode to play next on a show's details. `theme`, `parentTheme`: a show's theme tune path, on the show and on its seasons. `PlexPart.hasSceneThumbnails`: the server has scrubber thumbnails at `/library/parts/<id>/indexes/sd`.
- `KeychainStore`, `KeychainError`: the account token and server list, readable after first unlock.
- `PlexTV`: the plex.tv account API.
  - `createPIN(strong:)`, `authURL(for:)`, `checkPIN(_:)`, `waitForToken(_:every:now:sleep:)`: PIN sign-in. A strong PIN is for the browser sheet, which the app closes once polling sees the approval; a 4-character one is typed at plex.tv/link.
  - `servers()`: servers with this user's token for each.
  - `homeUsers()`, `switchHomeUser(_:pin:)`: Plex Home profiles; a switch returns that profile's token.
  - `account()`: the user a token belongs to (`/api/v2/user`), the account or the profile switched to.
- `PlexPIN`, `PlexHomeUser`: sign-in code and profile. `PlexHomeUser` is Codable, so the app keeps the active profile.
- `PlexWatchlist`: the profile's watchlist on discover.provider.plex.tv, with the account token. `items(start:size:)`, `contains(guid:)`, `add(guid:)`, `remove(guid:)`. `catalogueKey(guid:)` is nil for titles matched by an older agent, which cannot be watchlisted.
- `SnapshotStore(directory:)` and `ResponseSnapshot(store:scope:mode:)`: raw Plex responses kept on disk per `SnapshotScope` (server and profile id, never a token or address), bounded per response, scope and store, and by age; `removeAll()` and `remove(profile:)` drop them and cancel writes in flight. `PlexLibrary.snapshotting(_:)` and `PlexWatchlist.snapshotting(_:)` return a copy whose reads record (`.record`) or answer from disk without the network (`.replay`, throwing `SnapshotUnavailable` for a request never recorded), so Home's loading code runs unchanged over stored bytes.
- `MediaDeletion(server:watchlist:arr:requests:)`: `delete(_:alreadyDeleted:afterDelete:)` deletes a title on the server, then cleans up after it in this order, each step with its own result in the returned `MediaDeletionResult`: the Watchlist entry (`WatchlistCleanup`: `unchanged`, `removed(guid:)`, `failed(guid:)`; rules in PARITY, Delete media), Radarr or Sonarr (`arr`), and Seerr (`requests`), both `ServiceCleanup` (`notConnected`, `notApplicable`, `unmatched`, `removed`, `refused`, `failed`; its raw values are those names). A failure never stops the next step. `retry(_:alreadyDeleted:)` repeats only the failed steps from `result.ticket`, a `DeletionTicket` (`Codable`) holding what was read before the server forgot the title (guid, title, year, TMDB and TVDB ids); the ticket is nil when nothing failed. `delete` is `deleteFromServer(_:)` (the delete and its recheck, answering `(outcome, ticket)`, no other service asked) followed by `cleanUp(_:alreadyDeleted:)` (every step, from that ticket), which a caller that answers each call once, like the Android bridge, runs apart so the title leaves its lists before the other services answer. It talks to `DeletionServer` (`PlexLibrary`, which also lists `externalIDs`), `WatchlistAccount` (`PlexWatchlist`), `ArrAccount` (`ArrServices`) and `RequestsAccount` (`SeerrClient`); waits go through an injected `sleep`. `PlexLibrary.deleteItem(_:)` and `deleteVersion` wait 180 s; `allLeaves(of:)` lists a show's episodes. `PlexMetadata.parentGuid` and `grandparentGuid` name an episode's season and show.
- `ArrClient(kind:config:transport:)` (`Arr/`): Radarr's or Sonarr's v3 API with `X-Api-Key`. `version()` proves the address and key; `remove(_:)` takes an `ArrTitle` (`.movie(tmdbID:title:year:)` for Radarr, `.series(tvdbID:title:)` for Sonarr), deletes it with its files and adds it to the import exclusion list (`addImportExclusion` / `addImportListExclusion`), or only posts the exclusion when the service no longer holds it. `ArrConfig.parse` follows `BazarrConfig`'s rules. `ArrServices` holds whichever of the two are connected. `SeerrClient.removeMedia(_:tmdbID:)` deletes Seerr's media record and its requests (`DELETE /api/v1/media/{id}`, needs manage-requests) without blocklisting.

## Server address (`Connection/`)

- `PlexServer`, `PlexConnection`: a server with this user's token and its addresses. Codable, for the Keychain only. `PlexConnection.displayAddress` is the address as a person reads it: the IP a plex.direct name spells, and the port when it is not 32400. `ipAddress`: that IP, or nil for a host name.
- `HomePresence`: proof the phone is at home for the TV remote, from its own session or a probe of the paired TV; playback does not use it. Rules in docs/adaptive-playback.md.
- `ConnectionRanking.ordered(_:httpsRequired:)`: local, then remote, then relay; https before http, IPv4 before IPv6; duplicates dropped.
- `HomeNetwork.contains(_:)`: the hosts the app's transport security lets through without TLS (private, link-local and tailnet addresses, `.local` and single-label names); integrations allow plain http only to these.
- `ConnectionRanking.pick(_:graceExpired:)`: `use`, `wait` or `noneReachable` from probe outcomes so far.
- `ConnectionRanking.triesAlone(_:)`: only a remembered local address skips the probe. `upgrades(from:in:)`: the addresses in a better tier than the one in use.
- `PlexServerConnection` (actor): probes every address at once with `/identity` (no token; an answer from another machine counts as a failure). A remembered local address is tried alone first; a remembered remote one is not, since it may have won only while iOS asked for Local Network access or a VPN was on. Better-ranked addresses get 750 ms after the first answer. `connection()`, `currentConnection`, `reportFailure(of:)`, `reportFailure(at:)` (a download or other request made outside the library got no answer from that URL's address), `refresh()` (after a network change), `preferLocal()` (on foreground: while a remote or relay address is in use, probes the better ones and moves to the best that answers).

## Library (`Library/`)

- `PlexLibrary`: one server's library through its chosen address. Reads move to another address once when the chosen one stops answering; writes are never repeated.
  - `promotedHubs(count:)` (Continue Watching from `/hubs/continueWatching`), `sections()`, `search(_:limit:)`: home rows, libraries, search groups.
  - `items(in:query:start:size:)`, `alphabetIndex(in:query:)`, `genres(in:)`: one grid page (60 by default), its A–Z jump bar and the genres to filter by.
  - `collections(in:start:size:)`, `recommendedHubs(in:count:)`: a library's Collections and Recommended.
  - `list(_:start:size:)`: one page behind a key the server handed out (a row's "see all", a collection, a person); the key keeps its own query.
  - `metadata(_:)`, `children(of:)`, `related(to:)`: details with streams, markers, chapters and the next episode; seasons and episodes; similar titles.
  - `items(matchingGuid:)`: this server's copies of a catalogue title, e.g. a watchlist entry.
  - `markWatched(_:)`, `markUnwatched(_:)`, `removeFromContinueWatching(_:)`, `reportTimeline(_:)`: watched state and progress.
  - `RewatchRun`, `RewatchDismissals`, `offeringRewatch(of:)`: Continue Watching for a show watched again (DESIGN §8.1). A run starts reading the profile's views of the last 16 weeks with Home's load, and `continuing(_:dismissed:within:)` puts each show's next episode into Plex's row once however often it is called, nil past `within`. `PlexMetadata.rewatchedAt` marks a card it added, which plays from the start. `RewatchDismissals` holds the shows the profile took off, by guid, and goes in the profile's settings. `offeringRewatch(of:)` gives a show's page the same next episode.
  - `createPlayQueue(for:)`, `playQueue(_:)`: a queue that continues through the show for episodes.
  - `selectStreams(partID:audioStreamID:subtitleStreamID:)`, `playbackURL(path:query:)`, `transcodeURL(_:)`, `stopTranscode(session:)`: playback. These URLs carry the token because the player cannot send headers; they are never logged or cached. `transcodeURL(_:)` asks `/video/:/transcode/universal/decision` first and returns the stream on the address that answered it.
  - `transcodeSession(_:)`: the server's `PlexTranscodeSession` for a `TranscodeRequest.session` (speed, throttling, decisions, hardware), nil once it has ended; for the player's stats.
  - `refresh(_:)`, `externalIDs(_:)`: asks the server to re-read an item so a new file is listed, and an item's IMDb, TMDB and TVDB ids for Bazarr.
  - `searchSubtitles(_:language:)`, `addSubtitle(_:candidate:)`: the server's own subtitle agents for an item in one two-letter language, best match first, as `PlexSubtitleCandidate`s, and adding one. A candidate's key is good only for the search that found it; the server lists the added file a little later as a new selected stream named after the release.
  - `imageURL(_:width:height:scale:)`, `authorizationHeaders()`: artwork and headers for the image loader and the remux.
- `TimeLimit.answer(within:_:)`: what the work answers, or nil once the limit passes. The work is left to finish, not cancelled, because cancelling a request counts as the server address failing. The rewatch run and the server's decision on the original wait this way.
- `HomeRow`, `HomeLayout`: a profile's Home rows. A row is a Home hub or a library hub (id prefixed with the library's uuid). `arrange(_:)` orders rows by the saved placements, then unplaced ones in server order with their default visibility (library rows hidden); `save(_:)` keeps placements of rows the server did not send this time; `shownLibraries` names the libraries worth asking. Row ids go through `HomeLayout.stableID`, which drops the genre or person Plex rotates in `movie.genre.<section>.<id>` hubs, and a layout decodes leniently so one odd placement from an older version costs only itself.
- `ProfileSettingsStore`: a profile's settings saved and read under its Plex uuid; a profile with none takes those kept under the key the same sign-in used before (the empty uuid, or the uuid the Home list gave).
- `SectionQuery`: item type, sort, Unwatched filter and genre for a grid.
- `PlexPage`: one page and the total behind it.
- `AlphabetIndexEntry.entries(from:)`: jump-bar letters with the offset where each starts.
- `PagedLoader` (`@MainActor`, `@Observable`): grid paging.
  - `reload(using:)`: starts a new generation; pages from an older one are dropped. A load cancelled because its screen went away records no failure.
  - `refresh()`: the first page again with the last query; on failure the shown items stay, with `failure` set. `loadedAt` is when the first page last arrived.
  - `wantsNextPage(after:)`: whether that item is within three quarters of a page of the end, so a cell asks before it starts a task and a cell in the middle of the list starts none. `loadMoreIfNeeded(after:)`: fetches the next page when it is.
  - `ensureLoaded(through:)`: one request reaching a jump target, after any page already on its way.
  - `patch(_:)`: replaces a loaded item. Rows a shifted page repeats are skipped.
- `PlexPlayQueue`: `item(after:)`, `item(before:)` for Up Next.
- `PlexImageURL.transcoded(_:base:width:height:scale:)`: `/photo/:/transcode` at the view's pixel size, without a token, so the URL is the cache key.
- `PlaybackState`, `TimelineUpdate`, `TimelineCadence`, `TimelineReporter` (actor): progress reports on every state change and every 10 s while the state holds; a stop is sent once.

## Tracks (`Tracks/`)

- `TrackLanguage`: `eng`, `en` and `en-US` compare as English. `matches(_:)`, `name`, `variantName`, `.english`; `all` lists every two-letter language by English name.
- `AudioTrack`, `SubtitleTrack`, `TrackBadge`: tracks with plain menu labels ("English – 7.1", "English (on-screen text)", "Spanish (Latin America)") and Captions or Audio description badges. `SubtitleTrack.Kind` is full, captions, on-screen text or commentary.
- `MediaTracks(part:)`: one part's tracks, separate files last. An embedded subtitle with an exact separate-file twin, and an earlier copy of a file downloaded again (same release name and language), are hidden behind the newer file (`visibleSubtitles`, `visible(_:)`).
- `MediaTracks.arrived(_:kind:since:)`: a separate file in a language that was not listed before, such as a Bazarr download once Plex lists it. `listed(_:)` and `landed(_:since:)` find a Plex search result already in the menu and the file an added one became.
- `TrackRules.automaticSubtitle(in:audio:isAnime:)`: the English track the rules put on screen with this audio, nil when the file has none. The menu's On row turns it on.
- `SubtitleSearch(bazarr:library:ratingKey:language:bazarrBudget:)`, `run(lookup:target:tracks:tried:step:)`: Find Subtitles in one step. Bazarr goes first for at most the budget (20 s); the server's agents, asked at the same time, add their best file when Bazarr is not set up, unreachable, slow or empty. Reports each `Step` and an `Outcome` with the file added (`Added`) or why Bazarr gave none (`BazarrMiss`); `Tried` keeps a second search from adding the same file.
- `TrackRules.pick(from:isAnime:countries:choices:)`: the audio and the `SubtitleDecision` for one playback, with its source (`handPick`, `remembered` or `rules`) and whether the title played as anime. One pure decision for every platform; the rules are DESIGN §8.6 Track rules. A hand pick or the show's `TrackMemory` (in `choices`) wins; the server's selected streams and the file's default flags do not decide. Text ranks before pictures, which are never picked; full before captions and on-screen text; for anime the dub-matched script goes with the dub and the original-matched one with the original audio, and a remembered separate English file counts as English only, so the audio still picks `.en.cc` or `.en`.
- `SubtitleChoice` (`off`, `automatic`, `track(id)`), `AnimeOverride` (`automatic`, `anime`, `notAnime`).
- `Anime.matches(genres:countries:)`, `PlexMetadata.isAnime` (genre Anime, or Animation and Japan; `countries` reads `Country`), `AnimeLookup.tags(_:in:)`: an actor that reads a show once for all its episodes and answers `TitleTags` (`isAnime`, `countries`); a failed read answers the item's own tags and is not kept.
- `OriginalLanguage.languages(countries:)`: the language of audio to look for, from Plex's production country names (long ISO forms such as "Republic of Korea" and "Taiwan, Province of China" included, case-insensitive). For a title that is not anime, `TrackRules.pick` plays the main track in the language of the first country that has one, else the file's default track.
- `TrackMemory`, `RememberedAudio`, `RememberedSubtitle`: per-show memory described by language and kind, since stream ids differ in every episode. `TrackMemory.anime` holds the show's anime setting; saved data from before it decodes. `RememberedSubtitle(.automatic, in:)` is nil, which forgets a kept Off. `TrackMemory.storageKey(server:profile:item:)`; the app stores it.
- `CueMarkup.marking(_:)`, `CueMarkup.placing(_:)`, `CueAlignment`: an SRT sidecar's `{\anN}` tags are marked before the engine reads the file, which drops the tag and with it the place, and read back from the cue text, so the app draws a `{\an8}` cue at the top and never shows the tag.

Tracks titled Signs or Songs count as on-screen text, as the spec's forced-word list includes "sign" and "signs".

## Playback (`Playback/`)

- `DeviceCapabilities`: what the phone, screen and player can do; the app fills it.
- `PlaybackRouteDecider.decide(media:part:tracks:audio:subtitle:capabilities:limits:hevcSampleEntry:)`: `PlaybackRoute`.
- `ScrubPreviewPlan`: the player's own scrub previews, a slot every 10 s (`slot(at:duration:)`, `time(of:duration:)`, `fillOrder(playhead:duration:)`). `ScrubPreviewFillPolicy.allows`: the background fill runs while playing, not stalled or hot, on unmetered Wi-Fi without Low Data Mode (a local file always). `ScrubPreviewPacer`: 80 ms between frames while dragging. `ScrubPreviewDisk`: the frames as JPEGs per part id, 20 MB, oldest evicted.
- `TrailerAutoplay`: `dwell` (2 s); `decide(_ conditions:)` → `.play(muted:)` or `.hold` from the setting, Low Power Mode, Reduce Motion, a metered link, app activity, hero visibility, an open player and other audio; `directPart(of:capabilities:)` → the first trailer file the phone plays untouched.
  - Direct play for MP4/MOV with H.264 or hvc1 HEVC and playable audio.
  - On-device remux for other containers, hev1 HEVC, Dolby Vision 7 and audio the remux converts. Without the remux, the server copies the video instead.
  - Server re-encode for video the phone cannot decode, Dolby Vision it cannot show, HDR on an SDR screen, HLS level or frame-rate limits, a quality limit, or a picture subtitle the viewer picked, to burn in.
  - Unplayable audio is first swapped for a playable track in the same language. Text subtitles are never burned in; a picture subtitle burns only for a hand pick, or a remembered one when the video is re-encoded anyway.
- `ThemeMusic.key(for:)`: the tune a show's or season's page plays. `plays(_ conditions:)`: whether it plays now, from the setting, app activity, page visibility, an open player, other audio and a trailer with sound. `ThemeFade`: the tune's gain, rising over 1.5 s and falling over 1 s from wherever it is; `volume(level:)` is the setting times the gain squared.
- `PlaybackRoute`: kind, `RouteReason`s, played audio and whether it stands in, audio conversion, video re-encode, `SubtitleDelivery` (sidecar, in stream, burned in, not shown).
- `RouteReason`: plain-English reasons. `RouteLimits`: a server reason (on-device failure, direct play off, AirPlay), phone only (Direct play forced: never the server, unshowable subtitles not shown), bitrate cap, and `reach` (`RouteReach`).
- `RouteReach`: how near the server is for a file that needs the remux (docs/adaptive-playback.md). `decide(connection:mediaKbps:linkKbps:)`: a relay is `.relay`; with a recent link reading, `.nearByLink(kbps:)` at `needs(forMediaKbps:)` or more (3 times the file's rate, at least 20 Mbps) and `.remoteByLink(kbps:needs:)` below it; without one `.unmeasured`, which converts. The player sets `.remoteByServer` when `ServerLimit.holdsBack(output:source:)` finds the server's decision making the file's video at under nine tenths of its rate. `LinkProbe.isNeeded(route:reach:)`: any start but direct play with the link unmeasured; `LinkProbe.kbps(bytes:seconds:)` judges the read.
- `LinkMemory`: this run's link readings per server address. `record(_:to:at:network:)`; `recent(to:at:network:)`, no older than 30 min, from this network and not distrusted; `distrust(_:network:)` once the phone failed to read the file over the link, `isDistrusted(_:network:)`.
- `VideoQuality.lower(mediaKbps:)`: the highest preset at or below half the rate playing now, offered after a long network wait at a fixed quality.
- `QualitySetting`: `.auto` (the default) or `.fixed(VideoQuality)`; `all` for menus, `saved(legacy:)` reads the old fixed-only setting.
- `AdaptiveQuality(mediaKbps:linkKbps:cap:scores:map:tuning:source:view:streamID:now:)`: Auto's rung keeper (docs/adaptive-playback.md). `cap` is Save Data's highest quality. Optional `Picture` dimensions select the watchable floor; `floor` and `belowFloor` expose the minimum rung and whether the link can sustain it. `map` is the title's `QualityCurve` on this screen: the ladder is then Original and the curve's steps (`isMapped`), in place of the presets. `observe(Look)` takes link speed, buffer, network wait and an optional stream ID, rejecting a mismatched ID; it returns an `AutoRung` to move to or nil. Call `moved(to:at:)` once the move is over. `rung`, `estimateKbps` and `ladder` expose policy state; construct a new policy to discard measurements after a network change. `AutoRung`: `.preset(VideoQuality)` or `.mapped(StreamStep)`, with `quality`, `title` and `target` (a mapped rung's `DownloadTarget`, which `RouteLimits.target` carries to the route). `QualityScores`: a title's VMAF score per preset rung, capping a preset ladder's climb (nothing supplies them).
- `StallWatch`: what a wait in mid-play waits on. `check(now:position:run:)` → `.network(seconds:)`, `.stuck(ahead:cause:)` (a remux run idle for 1 s, or 30 s of output the player sits on: restart it at the playhead) or `.giveUp` (stuck again within 1 s of the last restart); `resume()` once playback moves.
- `StartRecovery`: a server transcode's start. `readyDeadline` (30 s) bounds the player's wait for the stream; `failed()` → `.retry(after:)` (2 s, then 5 s, each a new session after the addresses are probed again) or `.giveUp`; `reset()` once it plays or on Retry.
- `ConversionWatch`: whether the server lost the conversion a stream plays from (docs/DESIGN.md §8.6). `notFound(at:bufferAhead:)` and `failed(at:)` → `.wait`, `.recover(_:missed:)` (two 404s within 6 s, one with under 10 s buffered, or the item failing with a 404) or `.giveUp` (a third loss within 60 s, left to `StartRecovery`); `recovered(at:)` once the stream is being replaced, `streamStarted()` for each new stream; `isNotFound(domain:code:comment:)` reads an AVPlayer error or error-log entry.
- `SkipTaps`: the player's tap rule as a state machine. `tap(_ side:at:)` → `.skip(side)`, `.toggleAspect` or `.single`; `SkipTapMode.doubleTap` skips only on a true double-tap (`doubleTapWindow` 0.3 s), `.chained` also skips on same-side taps within `chainWindow` (1.5 s) of a skip; `reset()`. `TapSide` is the third of the picture a tap landed in.
- `VideoOrientation`: the Video Orientation setting (`followDevice`, `startInLandscape`, `lockToLandscape`) and each one's `title`. `OrientationHold(_:screenSideways:held:)` is what an open player asks of the screen: `holdsLandscape` while it keeps the screen on its side, `turned(to:)` for each new `PhoneHold` (`.upright` or `.sideways`; Start in Landscape lets go at the first `.sideways`), `turnsUprightOnClose` when closing turns the screen back.
- `FormatBadge`: `make(video:media:audio:route:)` → the first-start badge: `resolution` (by width), `range` (HDR10, HDR10+, HLG, Dolby Vision; none when the server re-encodes, HDR10 for a Dolby Vision profile 7 base layer), `sound` (Atmos, 5.1, 7.1; only for passed-through audio), `spoken` for VoiceOver.
- `TranscodeRequest`: start offset, quality, video copy and burn-in for `PlexLibrary.transcodeURL(_:)`. The server takes audio and subtitle from the streams set with `selectStreams`. `init(live:)` streams a tuned channel; the server copies H.264 and HEVC and converts MPEG-2.
- `CastReceiver(modelName:)`: what a Chromecast plays (4K HEVC for Chromecast Ultra and Google TV Streamer, 1080p H.264 for the rest). `CastRouteDecider.decide(media:part:tracks:audio:subtitle:receiver:limits:)`: the receiver opens an MP4 with video it decodes and AAC or MP3 first itself, else the server's HLS of H.264 and AAC; a picture subtitle the viewer picked is burned in, and a text subtitle is not shown, since the Default Media Receiver draws none of Plex's formats.
- `CastStream`: the receiver's URL, content type and server session. `address(current:among:)` swaps plain http for an HTTPS address of the same machine; `file(part:base:token:)`, `transcode(_:base:identity:isLocal:token:)`. `PlexLibrary.transientToken()`: the 48-hour delegation token the receiver holds instead of the account's.
- `CastProgress`: one load's state from `CastStatus` updates: position between updates, `PlaybackState` for the timeline, and how it ended (finished, stopped, failed, replaced).
- `MiniBarSize`: how tall the mini player's bar is, and its picture (DESIGN §8.6.1). `init(least:margin:width:)` gives `height`: twice `least`, but never more than a 16:9 picture taking 40% of `width` allows, and never under `least` (a zero width gives `least`). `pictureHeight` and `pictureWidth` are the picture's size in it: the height less `margin` above and below, in 16:9.

## Live TV (`Live/`)

The endpoints and the route rules are in `docs/LIVE-TV.md`.

- `PlexLiveTV(library:)`: one server's Live TV and DVR.
  - `dvrs()`, `channels(_:)`: DVRs with their devices and channel mappings; the lineup's enabled channels in number order ("2.1" < "2.10" < "10.1"), each joined to the device that receives it (a live one first).
  - `guide(_:channels:from:to:)`: airings overlapping a window, one per channel a programme airs on; channels no device maps are dropped. `channelFilters(_:)`, `channelKeys(in:)`: the provider's genres and their channels.
  - `tune(_:session:)` → `PlexLiveSession`, whose `sessionIdentifier` names the tune, the transcode (`streamURL(_:)` with `TranscodeRequest(live:)`), the timeline reports (`reportTimeline(_:)` with `LiveTimelineUpdate`) and `stopStream(_:)`; the transcoder finds the tuned stream only under that name. `stopStream(_:)` also cancels the session's grab (`grabKey`), which frees the tuner.
  - `recordOptions(_:)` → `RecordOption`s (this episode, all episodes, the movie; `[RecordOption].defaultOption` is what a plain Record takes, never the whole show), `record(_:values:)`, `update(_:values:)`, `rules()`, `scheduled()`, `cancel(_:)` (deletes the grab: skips an airing or stops one recording), `stop(_:deleting:)` (the grab, then a rule), `delete(_:stopping:)` (a rule, after its running airings). `LiveRecordings.holdingTuner(for:dvr:)` finds the recording that has taken a channel's tuner.
- `LiveDVR`, `TunerDevice`, `LiveChannelMapping`, `LiveChannel`, `LiveAiring`, `LiveChannelFilter`: values, Codable for the guide cache.
- `LiveGuide`: channels and per-channel airings for the loaded span. `airing(on:at:)`, `nowAndNext(on:at:)`, `airings(on:from:to:)`, `merging(_:from:to:channels:)` (a refreshed span replaces what it covers; an overlap is cut at the later start), `trimmed(before:)`.
- `GuideCache` (actor): the last guide per server and DVR on disk, loaded re-anchored to now (up to 2 h of past airings) or nil once it ends before now.
- `RecordingRule`, `ScheduledRecording`, `RecordSetting`, `LiveRecordings.mark(for:)` → `RecordingMark` (scheduled, series, recording, failed, recorded) for the guide's record glyphs.
- `LiveRouteDecider.route(_:_:)` with `RouteContext` → `LiveRoute`: `.direct(URL)`, `.plex(PlexRouteReason)` or `.protectedChannel`, by the first matching rule of §2.2.
- `HDHomeRunClient`: a tuner's `discover.json` (0.5 s timeout, the reachability check) and `lineup.json` (`HDHomeRunChannel` with codecs, HD and DRM when the tuner sends them).
- `LiveSource` (`@MainActor` protocol): what the live player plays through (play, pause, resume, `seek(behindLive:)`, stop); `LiveState`, `LiveError`.
- `LiveTimeshift`: where a live stream plays against live (`isPaused`, `behindLive`, `reach`). `isBehindLive` (paused, or 3 s or more behind), `canSkipBack`, `skipped(by:)` (a skip's landing, within the buffer and snapped to live within 3 s); `hls(seekable:position:liveOffset:isPaused:)` and `hlsPosition(behindLive:seekable:liveOffset:)` map the Plex path's HLS player times.

## Subtitles (`Subtitles/`)

- `BazarrConfig.parse(address:key:)`: checks a typed address and key; plain http only for home-network addresses.
- `BazarrClient`: `status()` (Bazarr, Sonarr and Radarr versions), `find(_:)` (a `BazarrLookup` by external id, then file name, then title and year, to a `BazarrTarget`; it reads the titles Bazarr's title search names before falling back to the whole list), `search(_:)` (`BazarrSubtitle`s, best score first), `download(_:for:)`.
- `SpeechDock.origin(_:)`: checks a typed service address (an http(s) origin alone; plain http only on the home network). `identity(server:ratingKey:media:audio:subtitle:)`: the choice SpeechDock can time (English sidecar text and English audio in a one-part file), or nil. `cues(_:)`, `alignable(_:)`, `window(_:asked:due:offset:ahead:)`: the file as the service reads it, the cues it times and the next window to ask about.
- `SpeechDockClient`: `health()` (the service's version), `align(_:)` (a `SpeechDock.Request` window to a `SpeechDock.Answer`: measured word starts by cue ordinal, or busy, or refused).
- `SubtitleLook`: the subtitle style: the TV's presets, font, size, colour, edge, box, position, line spacing, blending with the video and file styling. `init(preset:)`, `isCustom`.
- `SubtitleTiming`: a subtitle offset in 0.1 s steps, up to 60 s either way.
- `SubtitleReveal.estimate(_:duration:by:)`, `visibility(of:at:)`: Reveal as Spoken timing estimated from a cue's text and length. `measured(_:starts:by:)` takes SpeechDock's word starts instead; `spoken(_:)` is about how long a text takes to say.

## Seerr (`Seerr/`)

- `SeerrConfig.parse(address:apiKey:)` validates an HTTP(S) service address and optional key; plain HTTP is limited to home-network addresses. `Auth.plex` uses the Plex profile token; `Auth.apiKey` acts as the key’s owner. `SeerrError` distinguishes connection, authentication, permission, quota, duplicate request, missing title and service failures.
- `SeerrClient` (actor) takes a config, transport, optional Plex token and saved session, plus an `onSession` callback. `version()`, `signIn()`, `me()` and `serverSettings()` check the service, account and request settings. It maintains its own session and CSRF cookies; a Plex session rejected with 401 or 403 is renewed once and the call retried.
- `discover(_:page:)`, `search(_:page:)` and `details(_:tmdbID:)` return movies and series. `SeerrShelf` names Trending, Popular Movies, Popular Series, Upcoming Movies and Upcoming Series. `requests(of:take:)` returns the account’s latest requests, newest first, with optional title details. `request(_:)` submits a `SeerrOrder`; HTTP 202 and 409 mean `alreadyRequested`.
- `browse(_:page:)` returns one `SeerrTitlePage` of a `SeerrFeed`: Trending, or Discover with a `SeerrBrowseQuery`. The query holds the kind, genre, `SeerrSort` with its order, Upcoming (released from today on), `SeerrEra`, original language (Seerr’s `language` parameter, which it passes to TMDB as `with_original_language`), a minimum rating, `SeerrRuntime` and `SeerrStreaming`, and builds the `/discover/movies` or `/discover/tv` parameters; a rating sort or floor ignores titles with fewer than 100 votes. `genres(_:)`, `languages()`, `watchRegions()` and `watchProviders(_:region:)` list the choices, each asked once; `genreCards(_:)` lists the genres with a backdrop each for Discover’s cards. `SeerrDiscoverRow.all` is the Discover page’s rows in order. `SeerrPager` pages a feed by page number for a grid: it drops a page that arrives for an older reload, skips titles already shown, and `refreshLoaded()` reloads every page shown.
- `SeerrUser`, `SeerrPermissions`, `SeerrServerSettings`, `SeerrTitle`, `SeerrDetails`, `SeerrMedia`, `SeerrRequest` and `SeerrSeason` describe the account, catalogue and request state. Permission and server settings control standard and 4K requests, partial season requests and specials.
- `SeerrMedia.badge(is4K:)`, `SeerrRequest.badge` and `openRequest(is4K:)` describe status and the latest open request. `plexLink(serverID:)` returns a matching Plex item or an unconfirmed rating key that must be checked against the TMDB identifier before use. `SeerrDetails.seasonChoices(is4K:settings:)`, `canRequest(is4K:user:settings:)` and `order(seasons:is4K:settings:)` enforce quality and season choices; `watchlistAddRequests(user:pulsarr:)` detects automatic Watchlist requests. `TMDBImage.url(_:pixels:)` selects an image size.

## Downloads (`Downloads/`)

- `DownloadQuality`: Original or a `DownloadTier` (High, Medium, Low, aiming at VMAF 95, 90 and 85). `DownloadQualityPlan(media:animated:hevc:originalPlays:answer:screen:)`: the Download menu's `Option`s (quality, `DownloadTarget`, measured or estimated, bytes, resolution) and `option(for:)`, a default quality's choice. Estimates follow the version's height, video bitrate, codec, frame rate and animation genres (`isAnimated(genres:)`); no tier exceeds the original's bitrate, and a 4K HEVC High joins for a 4K original on a phone that decodes HEVC. A measured title asks HomeLabber's video bitrate and height for Low and Medium (High follows the tier's own); a `.useOriginal` answer leaves Original as the only option.
- `HomeLabberConfig.parse(address:token:)` (the token starts `hlmq_`); `HomeLabberClient`: `status()` (`QualityMapStatus`: coverage, `lastRun`, `encoder`) and `answer(server:ratingKey:)` → `QualityMapAnswer`: `.scored(QualityMapEntry)`, `.useOriginal(sourceKbps:mediaID:)` (smaller than any conversion: download the file) or `.unscored`. `verified(for:)` turns an answer for another version of the file (`mediaId`) into `.unscored`; `curve(for:screen:)` is the `QualityCurve` for a phone (`phoneTiers`, `vmafPhone`) or tablet (`ScreenClass`), falling back to `tiers` and `vmaf`. `QualityMapCache` keeps a session's answers (an unscored title for 10 minutes; a failed request silences every title for a minute).
- `TranscodeLadder.search(for:attempts:decide:)`: the `maxVideoBitrate` cap whose decision comes closest to a target's bitrate at its height.
- `HLSPlaylist`: a master playlist's `variant(in:)`; a media playlist's `segments(in:)` and `next(after:in:)`.
- `StreamedFile`: one `.ts` from a conversion's segments. `prepare` drops a write cut short, `append(_:ending:to:stream:)` trims a new session's repeat (`TransportStream`), and `pieces(of:)` with `absorb(into:stream:)` join the segments iOS fetched in the background, in order.

## Navigation (`Navigation/`)

- `Destination`: Home, Library, Live TV, Watchlist, Search, Requests, Downloads.
- `TabLayout`: the order and the tabs switched on; `standard`, `init(savedOrder:savedShown:)` (unknown names dropped, missing ones appended off), `tabs(available:)`, `canSwitch(_:available:)`, `setTab(_:_:available:)`, `reorder(_:)`. Home is always a tab, Search always last, at most `maximumTabs` (5).

## Remote (`Remote/`)

The floating LumaTV remote's geometry and input maths; LumaRemoteKit owns the connection and the keys.

- `RemoteDock`: one of `rows` (5) edge spots on a `DockSide` (`start` or `end`); `default` is the right side's fourth, `all` lists the ten, `encoded` and `init?(decoding:)` save and read it.
- `RemoteSpace`: the room the remote has: the window, its safe area, the top of the bottom bar (`barTop`, never less than the home indicator's reach) and the keyboard's top. `orbField` is where the orb may rest, a 16 pt margin inside the safe area and above the bar and keyboard; `panelBounds` is where the panel may be, above the keyboard and free to cover the bar; `orbRect(for:size:)` is the orb at a dock.
- `OrbDimming`: `isDimmed(overContent:panelOpen:idle:)` is true once the orb has sat untouched for `dwell` (4 s) over content with the panel closed; it then shows at `dimmedOpacity` (0.4).
- `PanelFractions`: the panel's rectangle as fractions of the window, so it survives a rotation or another size; `init(rect:in:)`, `rect(in:)`, `encoded`, `init?(decoding:)`. `PanelHandle.all`: the eight edge and corner handles that resize it.
- `RemoteLayout`: `init(width:height:visible:tray:)` places the pad and the `RemoteStrip`s (nav, volume, channel, playback, launchers) for a panel size and the visible `RemoteModule`s: `shape` is `column` when tall, `row` when wide, `compact` when small; `area`, `pad`, `strips` (`StripPlacement`, with `keyRects` and `moduleRects`) and `dropped` (the modules that no longer fit). `RemoteMetrics` holds the sizes: grid 4 pt, margin 16, gap 12, key 56, header 56, pad minimum 144, tray 56, panel minimum 232. `Set<RemoteModule>.all` is every module.
- `RemotePadMode`: `dpad`, `joystick`, `touchpad`; anything unknown or unsaved is `dpad`.
- `JoystickRepeater`: turns a held joystick into `DpadKey` repeats, slow near the centre and fast at the edge. `TrackpadTracker` and `ScrollMomentum`: the touchpad's taps, drags, two-finger scroll and fling. `AirMouseMath` and `OneEuroFilter`: the air mouse's turn rates and their smoothing.
