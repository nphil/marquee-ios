# Seerr integration handoff

The Seerr branch includes discovery, search, title details, requests, settings, fake-service fixtures and UI coverage. Discover lists Trending, Popular Movies, Movie Genres, Upcoming Movies, Popular Series, Series Genres and Upcoming Series; a row's chevron or a genre card opens a paged grid with genre chips and a View menu (sort, release decade, original language, rating, runtime, streaming service and region, upcoming only). Requests use the active Plex profile or the configured API key; session cookies are scoped to the saved address and profile. A duplicate request refreshes the title and request list.

The fake server serves Seerr and TMDB fixtures without contacting a real service. Integrate this branch with the rest of the batch before running the combined iOS build and simulator UI suite. The iOS build, simulator appearance (the Discover rows, the browse grid and its View menu, in dark, light and large text) and request flows remain unverified on this branch. The discover, genre, language and streaming service calls follow Seerr's OpenAPI spec and server source and have not been sent to a live server.
